# Варианты дизайна Header

## Вариант 1: Минималистичный с балансом
- Простой, чистый дизайн
- Баланс пользователя рядом с профилем
- Меньше элементов, больше пространства

## Вариант 2: Градиентный фон
- Яркий градиентный фон header
- Более выразительные цвета
- Современный, привлекательный вид

## Вариант 3: С акцентом на профиль
- Большой профиль пользователя по центру
- Баланс и дополнительная информация
- Более личный подход

## Вариант 4: Тёмная тема с неоновым эффектом
- Тёмный фон с неоновой подсветкой
- Цветовые акценты на элементах
- Футуристический вид

## Вариант 5: С дополнительными кнопками
- Кнопки навигации (настройки, уведомления)
- Больше функциональности
- Более полноценный header

## Вариант 6: Компактный с иконками
- Меньше элементов
- Больше информации в меньшем пространстве
- Оптимизирован для мобильных
